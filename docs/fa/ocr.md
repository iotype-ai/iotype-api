# OCR — تبدیل عکس و پی‌دی‌اف به متن

استخراج متن فارسی از اسناد اسکن‌شده، عکس صفحات، و فایل‌های PDF. موتور پردازش تصویرمحور است، بنابراین روی PDF اسکن‌شده و PDF دارای لایه‌ی متنی یکسان عمل می‌کند.

**آدرس:** `POST /io/v1/ocr` · **ناهمزمان**

## درخواست

</div>

```bash
curl -X POST https://iotype.com/io/v1/ocr \
  -H "Authorization: Bearer $IOTYPE_TOKEN" \
  -H "Accept: application/json" \
  -H "X-Requested-With: XMLHttpRequest" \
  -F "file=@contract.pdf" \
  -F "should_summarize=true"
```

<div dir="rtl">

**بدنه** — multipart/form-data

| پارامتر | نوع | الزامی | توضیح |
| --- | --- | --- | --- |
| `file` | فایل | بله | PDF یا JPG |
| `should_summarize` | boolean | خیر | تولید خلاصه از متن استخراج‌شده |

## پاسخ

بلافاصله برمی‌گردد و **شامل متن نیست**:

</div>

```json
{
  "file": {
    "uuid": "3c7d9a10-55b2-4e7c-8a31-77ab0c4d9e02",
    "name": "1712345999_3c7d9a10.pdf",
    "filename": "contract.pdf",
    "processes": [
      { "type": "ocr", "status": "processing", "result": null }
    ]
  }
}
```

<div dir="rtl">

با `uuid` به [`POST /io/v1/file/track`](files.md) مراجعه کنید تا یکی از پروسه‌ها مقدار `result` بگیرد.

</div>

```json
{
  "file": {
    "processes": [
      { "type": "ocr",       "status": "done", "result": "متن کامل سند ..." },
      { "type": "summarize", "status": "done", "result": "خلاصه سند ..." }
    ]
  }
}
```

<div dir="rtl">

پروسه‌ها را با `type` تشخیص دهید، نه با ایندکس.

## شرایط ورودی

کیفیت خروجی مستقیماً به کیفیت ورودی وابسته است. فایل ارسالی باید:

- **پس‌زمینه‌ی سفید** داشته باشد — پس‌زمینه‌ی رنگی یا بافت‌دار دقت را کم می‌کند
- **متن تایپی** باشد — دست‌خط پشتیبانی نمی‌شود
- **واضح** باشد — بدون لرزش و بدون بزرگ‌نمایی از تصویر کم‌کیفیت
- **بدون چرخش** باشد — صفحات کج یا چرخیده را پیش از آپلود اصلاح کنید
- **حجم متناسب** با تعداد صفحات داشته باشد

## آنچه استخراج نمی‌شود

**فقط متن.** نمودار، دیاگرام و جدول تبدیل نمی‌شوند. محتوای خانه‌های جدول ممکن است به‌صورت متن پراکنده و بدون ساختار ظاهر شود؛ روی حفظ چیدمان حساب نکنید.

اگر به داده‌ی جدولی نیاز دارید، یا باید متن خروجی را پس‌پردازش کنید، یا در انتخاب OCR برای آن سند تجدیدنظر کنید.

## SDK

</div>

```python
text = io.ocr("contract.pdf", summarize=True, wait=True)
```

```js
const text = await io.ocr("contract.pdf", { summarize: true, wait: true });
```

<div dir="rtl">

## مواردی که در مستندات نیامده

- حداکثر حجم فایل و حداکثر تعداد صفحات
- پشتیبانی یا عدم پشتیبانی از PNG، TIFF و WebP
- میزان مصرف توکن به ازای هر صفحه
- اینکه PDF چندصفحه‌ای یک `result` یکپارچه برمی‌گرداند یا یک پروسه به ازای هر صفحه
